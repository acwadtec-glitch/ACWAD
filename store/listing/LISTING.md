# بيانات صفحة المتجر (جاهزة للنسخ)

## الاسم
- AR: عالم الأكواد
- EN: Code World

## وصف قصير (≤80 حرف)
- AR: امشي في قاعات سيرفرات 3D واحلّ ألغاز برمجة وحسابات.
- EN: Walk 3D server halls and solve coding and math puzzles.

## الوصف الكامل (AR)
عالم الأكواد لعبة ثلاثية الأبعاد داخل قاعات سيرفرات ضخمة. امشي بين الرفوف والكابلات، وقابل أجهزة هولوجرام، وكل جهاز فيه لغز برمجي أو سؤال أو عملية حسابية.
- حلّ كل الأجهزة عشان تفتح البوابة وتنتقل من سيرفر لسيرفر.
- ألغاز بثلاث مستويات صعوبة: أسئلة اختيار، قراءة كود، وحسابات.
- جمّع النقاط واحذر من نفاد الطاقة.
- افتح شخصية "نوفا" بعد ما تخلّص 3 سيرفرات.
- العب أوفلاين لوحدك، أو أونلاين مع لاعبين تانيين في نفس القاعة.
- من غير تسجيل حساب ومن غير إعلانات.

## Full description (EN)
Code World is a 3D game set inside giant server halls. Walk between racks and cables, reach holographic terminals, and solve a coding riddle, question or math problem at each one.
- Solve every terminal to open the portal and jump from server to server.
- Three difficulty tiers: multiple choice, code reading and calculations.
- Earn points and keep an eye on your energy.
- Unlock the character "Nova" after finishing 3 servers.
- Play offline solo, or online with other players in the same hall.
- No account needed, no ads.
